# FieldPilot 后续迭代边界

## P1：形成可公开演示的独立项目

- 使用 FieldPilot 自己的高德、Tavily、Kimi 配置完成 1 天与 3 天真实请求复验。
- 记录每个外部步骤的 P50/P95、失败类型、Token 与成本；在有对照报告前不写优化百分比。
- 增加 Agent/服务单元测试、真实适配器契约测试、前端组件测试和一个浏览器端到端用例。
- 生成独立截图、演示视频、GitHub Release 与公网 URL，不复用原项目域名。
- 增加后端静态地图 URL 编码与真实多 Marker 回归测试。

## P2：只引入有业务价值的原规划技术

### 来自 ForenTrail：CrewAI Flows

仅当需要持久化任务状态、人工补充证据或有限反证循环时，将 Coordinator 替换为一个固定 Flow。Flow 仍只允许有界路由，不开放 Agent 自由对话。

### 来自 SiteVerum：LlamaIndex 证据检索

仅当外勤人员上传门店照片、检查表或 SOP 时，引入版本化文档/图片证据检索、引用和 Grounding 校验。没有真实文档集时不为了关键词加入 RAG。

### 来自 Federune：Pydantic Evals

在积累固定任务集后，用类型化数据集评测请求是否合法、点位是否重复、轨迹顺序是否正确、降级是否诚实、最终解释是否引用正确任务 ID。评测结果生成后才能进入简历。
