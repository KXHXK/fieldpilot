# FieldPilot 简历与面试事实口径

## 当前可用项目标题

**FieldPilot｜城市外勤任务编排 Agent（个人项目，MVP）**
FastAPI + Pydantic v2 + Vue 3 + TypeScript

## 当前可使用的简历描述

- 将已完成个人项目中的多角色任务分解与工具治理经验迁移到城市外勤场景，重新设计 `FieldTaskRequest`、目标点位、环境风险、驻点、每日任务与成本等领域契约，完成 FastAPI 到 Vue 结果工作台的独立业务闭环。
- 实现 4 个职责单一的 Agent 与 Coordinator，将点位发现和环境风险并行执行，再以确定性规则完成点位去重、跨日分配和成本计算；LLM 仅对结构化结果做受约束总结，失败时保留可用方案并返回降级状态。
- 建立无密钥可复现的上海 3 日合成案例，验证 6 个点位不重复、成本明细一致和工具状态可追踪；当前后端 5 条自动化测试及前端 TypeScript 生产构建通过。
- 完成任务顺序调整、删除、坐标/地图回退、文本导出与浏览器打印，并在界面区分 `success / mock / degraded`，避免将演示数据和外部服务失败伪装成实时成功。

## 面试 60 秒讲法

FieldPilot 是我把已经做过的结构化规划与真实 API 治理经验，二次开发成城市外勤任务编排场景的项目。它不是让模型直接给一个看起来合理的答案，而是先用 Pydantic 固定输入输出，再由 Coordinator 并行调度点位发现和环境风险两个角色，之后确定性选择驻点、去重点位、按天分配任务和计算成本，最后才允许 LLM 对已有计划做总结。任何外部服务失败都会回退并把状态交给前端。我目前先完成了可无密钥复现的上海 3 日 MVP、5 条后端测试和前端生产构建；真实服务独立复验、部署和更完整评测仍是下一步，所以简历不写未验证指标。
